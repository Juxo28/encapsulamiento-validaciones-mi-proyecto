# CashPilot Enterprise

Proyecto realizado en PHP para poner en práctica los conceptos de Programación Orientada a Objetos (POO).

## Temas implementados

* Clases y objetos.
* Constructores (`__construct`).
* Encapsulamiento.
* Atributos privados (`private`).
* Métodos Getters y Setters.
* Validación de datos.
* Herencia (`extends`).
* Uso de `parent::__construct()`.
* Uso de `parent::`.
* Polimorfismo mediante la sobrescritura de métodos.

## Clases creadas

* **Gasto:** Clase principal que almacena la información de un gasto.
* **GastoFijo:** Hereda de `Gasto` y agrega la periodicidad del gasto.
* **GastoVariable:** Hereda de `Gasto` y agrega el motivo del gasto.
